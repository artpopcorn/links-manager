# 💻 Локальная разработка с БД на VDS

## 🎯 Почему БД на VDS?

✅ **Преимущества:**
- Данные синхронизированы с продакшеном
- Не нужно настраивать Docker PostgreSQL
- Prisma Studio работает "из коробки"
- Нет проблем с подключением к БД

## 🚀 Быстрый старт

### Запуск разработки

```bash
./dev-with-vds.sh
```

Это автоматически:
1. Создаст SSH туннель к БД на VDS (порт 5434)
2. Запустит Next.js dev сервер (порт 3000)

### Ручной запуск

Если нужно запустить вручную:

```bash
# 1. Создать SSH туннель
ssh -f -N -L 5434:localhost:5432 root@109.205.58.19

# 2. Запустить dev сервер
npm run dev
```

## 🗄️ Prisma Studio

### Для продакшн БД (VDS)

```bash
# Создать туннель
ssh -f -N -L 5434:localhost:5432 root@109.205.58.19

# Запустить Prisma Studio  
npx prisma studio --port 5555
```

Откройте: **http://localhost:5555**

## 📋 Полезные команды

### Проверить SSH туннель

```bash
lsof -i :5434
```

### Остановить SSH туннель

```bash
killall ssh
```

### Перезапустить dev сервер

```bash
# Остановить (Ctrl+C)
# Снова запустить
./dev-with-vds.sh
```

## 🆘 Решение проблем

### Ошибка "port 5434 already in use"

```bash
# Найти процесс
lsof -i :5434

# Остановить
kill <PID>
```

### Не могу подключиться к БД

```bash
# Проверить SSH туннель
ssh -L 5434:localhost:5432 root@109.205.58.19

# Должен появиться приглашение SSH, туннель работает
```

### Dev сервер не видит изменения

```bash
# Перезапустить с очисткой кэша
rm -rf .next
./dev-with-vds.sh
```
